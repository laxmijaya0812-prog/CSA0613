# CO2_AT3 – Design and Analysis of Algorithms

## Student Information
- **Course:** Design and Analysis of Algorithms
- **Assessment:** CO2_AT3

## Overview
This repository contains the solutions for the assigned CO2 Assessment 3 questions. Each question is implemented as a separate program and includes the required documentation and analysis.

Each question folder contains:
- **Source_Code** – Python program.
- **Report** – Problem statement, explanation, algorithm, source code, output, screenshots, analysis, and conclusion.
- **Supporting Files** – Additional files (if any).

## Programming Language
- Python 3

## Software Requirements
- Python 3.x
- Visual Studio Code / PyCharm / IDLE

## How to Run
1. Open the Python source file.
2. Execute the program.
3. Observe the output displayed on the console.

## Learning Outcomes
- Debug existing algorithms.
- Optimize algorithm performance.
- Analyze best, average, and worst-case complexities.
- Improve code readability using comments and proper structure.
