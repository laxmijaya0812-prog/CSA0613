This repository contains the solutions for the assigned CO3 Assessment 2 questions. Each question has been implemented separately and includes the required source code, report, and supporting files.

The report for each question includes:
- Problem Statement
- Algorithm
- Source Code
- Output
- Analysis
- Time Complexity
- Conclusion
- Screenshots of the source code and output

## Programming Language

## Software Requirements

- Visual Studio Code / PyCharm / IDLE (or any Python IDE)

1. Open the required question folder.
2. Navigate to the **Source_Code** directory.
3. Run the Python program using any Python IDE or the command line.
