# CO3_AT1 – Design and Analysis of Algorithms

## Student Information
- **Course:** Design and Analysis of Algorithms
- **Assessment:** CO3_AT1

## Overview
This repository contains the implementation and analysis of the assigned CO3 Assessment 1 question. The project focuses on evaluating the performance of the Quick Sort algorithm on datasets stored in secondary memory by measuring execution time and analyzing disk I/O operations.

The repository includes:
- **Source_Code** – Python implementation of the algorithm.
- **Report** – Documentation containing the problem statement, algorithm, source code, execution results, screenshots, analysis, time complexity, and conclusion.
- **Supporting Files** – Input datasets, output files, or any additional resources required for execution.

## Programming Language
- Python 3

## Software Requirements
- Python 3.x
- Visual Studio Code / PyCharm / IDLE (or any Python IDE)

## How to Run
1. Open the project folder.
2. Navigate to the **Source_Code** directory.
3. Execute the Python program.
4. Observe the execution time, sorting results, and performance analysis.

## Learning Outcomes
- Understand the Quick Sort algorithm and the Divide and Conquer strategy.
- Evaluate algorithm performance using execution time and I/O operations.
- Analyze the impact of secondary memory (disk access latency) on sorting efficiency.
- Compare algorithm suitability for internal and external sorting.
- Interpret experimental results using time complexity and practical performance.
