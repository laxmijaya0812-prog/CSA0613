## Overview

This repository contains the conceptual analysis and comparison of two important algorithm design principles:

* Principle of Optimality
* Greedy Choice Property

The assessment analyzes how Dynamic Programming and Greedy algorithms approach resource allocation and optimization problems.

## Topics Covered

* Principle of Optimality
* Dynamic Programming
* Greedy Choice Property
* Resource Allocation Problems
* Optimal Substructure
* Local vs Global Optimization
* Algorithm Correctness
* Algorithm Optimality
* Limitations of Dynamic Programming
* Limitations of Greedy Algorithms

## Comparison

Dynamic Programming solves problems by combining optimal solutions to subproblems, while Greedy algorithms make locally optimal choices at each stage.

The choice between these paradigms depends on whether the problem satisfies optimal substructure, overlapping subproblems, and the Greedy Choice Property.
