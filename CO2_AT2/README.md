# CO2_AT2 – Design and Analysis of Algorithms

## Student Information
- **Course:** Design and Analysis of Algorithms
- **Assessment:** CO2_AT2

## Overview
This repository contains the solutions for the assigned CO2 Assessment 2 questions. Each question has been implemented as a separate program and includes the required documentation and supporting materials.

Each question folder contains:
- **Source_Code** – Program implementation.
- **Report** – Documentation including the problem statement, algorithm, source code, output screenshots, analysis, time complexity, and conclusion.
- **Supporting Files** – Any additional files required for execution (if applicable).

## Programming Language
- Python 3

## Software Requirements
- Python 3.x
- Any Python IDE (VS Code, PyCharm, IDLE, or similar)

## How to Run
1. Open the source code file in a Python IDE or editor.
2. Run the program.
3. Verify the output generated by the program.

## Learning Outcomes
- Understand and implement Design and Analysis of Algorithms concepts.
- Analyze algorithm correctness and efficiency.
- Evaluate time and space complexity.
- Document program implementation and results.
